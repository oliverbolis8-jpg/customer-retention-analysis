# Customer Retention Analysis using Python

## Project Overview

This project analyzes customer purchasing behavior to identify retention patterns, customer segments, and churn risk using Python and data analytics techniques.

## Objectives

* Analyze customer purchasing behavior
* Perform RFM (Recency, Frequency, Monetary) analysis
* Segment customers based on spending behavior
* Identify customers at churn risk
* Visualize customer retention insights

## Tools & Technologies Used

* Python
* pandas
* matplotlib
* seaborn
* Jupyter Notebook

## Key Features

* Data Cleaning
* Revenue Calculation
* RFM Analysis
* Customer Segmentation
* Churn Risk Analysis
* Data Visualization

## Visualizations Included

* Customer Revenue Distribution
* Customer Segments
* Churn Risk Analysis
* Recency vs Monetary Scatter Plot

## Key Insights

* A small percentage of customers generated the majority of revenue
* Customer spending distribution was highly skewed
* High-value customers were identified using RFM analysis
* Some high-value customers showed elevated churn risk

## Files Included

* Jupyter Notebook (.ipynb)
* Dataset File
* Exported Analysis Results (.csv)
* Visualization Images

## Conclusion

This project demonstrates how data analytics techniques can help businesses understand customer behavior, improve retention strategies, and identify churn risk.
